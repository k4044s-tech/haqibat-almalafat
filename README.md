# نَسَق — ملفاتك المدرسية جاهزة ومنسّقة

تطبيق ويب يعمل في المتصفح لإعداد الملفات المدرسية وطباعتها لجميع المعلمين والمعلمات:
ملفات الأداء الوظيفي (المعلم/ة، القائد/ة، الوكيل/ة، الموجه/ة الصحي/ة، الموجه/ة الطلابي/ة)،
الخطط العلاجية والإثرائية، الفاقد التعليمي، الخطة التشغيلية، خطة التحسين، الشراكة المجتمعية،
مجتمعات التعلم المهنية، التوجيه الطلابي، الصحة المدرسية، المناوبة والإشراف، النشاط الطلابي، وملفات المعلم.

- **مولّد الشهادات:** شهادة لكل طالب من قائمة الفصل (شكر، تفوق، حضور، مشاركة، تخرج، شكر للمعلمين) بثلاثة تصاميم ونص قابل للتعديل.
- **المتجر:** شراء الملفات منفردة بتحويل بنكي ورفع الإيصال، وملفات مجانية للتجربة، ولوحة للمشرف لاعتماد الطلبات وتحديد الأسعار. التفاصيل في `SETUP-SUPABASE.md`.
- **قاعدة بيانات SQL:** تعمل الحقيبة على Supabase (PostgreSQL) عبر `supabase/schema.sql`، مع بقاء Firebase والوضع التجريبي خيارين.
- **محرر مثل Word داخل الحقيبة:** شريط بتبويبات (الرئيسية، إدراج، الجدول، الصورة، الصفحة، مراجعة): خطوط وأنماط وتباعد أسطر، وإدراج جداول وصور ورموز وخانات توقيع، وإضافة أعمدة وصفوف ودمج خلايا، وإضافة صفحات وتكرارها وحذفها، وبحث واستبدال.
- **منصة البطاقات:** تصاميم معايدة وتهنئة جاهزة (العيدان، رمضان، اليوم الوطني، يوم التأسيس، العودة للمدارس، يوم المعلم، التخرج، شكر وتقدير، العام الهجري) أو رفع تصميم خاص، وتحميل بطاقات بأسماء الطلاب في ملف مضغوط، ونشر رابط وباركود يكتب فيه الزائر اسمه ويحمّل بطاقته.
- **حقيبة المعلم المتميز:** الهوية المهنية والممارسات التدريسية والتطوير والإنجاز مع الشواهد.
- **توزيع الأسابيع الدراسية 1448هـ:** المواعيد المهمة، وأسابيع الفصلين بالتاريخين الهجري والميلادي مع الإجازات، وجدول توزيع المنهج على الأسابيع.
- **الجمع التلقائي وتحليل النتائج:** يُحسب المجموع والنسبة والتقدير أثناء رصد الدرجات، مع صفحة «تحليل نتائج الفصل».

## المزايا
- سجل متابعة الطلاب بتوزيع درجات يبنيه المعلم (بنود رئيسية وفرعية ودرجات وعدد خانات) وقوالب جاهزة وغلاف لكل فصل ومادة
- شريط تنسيق ثابت أعلى الصفحات، مع تحديد عدة خلايا أو عمود كامل وتنسيقها معًا: الخط والحجم والغامق والمائل والألوان والتظليل وتعبئة الخلايا والمحاذاة والقوائم ونسخ التنسيق، وإدراج صفوف الجداول وحذفها
- قسم كشوف الطلاب (16 كشفًا): تُدخل أسماء الفصل مرة واحدة أو تُستورد من Excel/CSV فتظهر في جميع الكشوف
- تعديل مباشر لأي نص وإضافة صور الشواهد، والتحكم بعددها في كل صفحة (1–8)
- تحويل الشواهد إلى باركود QR يُطبع بدل الصورة ويفتح الشاهد عند المسح
- 8 ألوان و3 أنماط للغلاف و6 خطوط
- صيغة معلم / معلمة
- طباعة A4 وحفظ PDF
- الحفظ التلقائي في المتصفح دون حساب أو خادم

## الحسابات والصلاحيات
- الاستعراض متاح للجميع، والتعديل والطباعة بعد تسجيل الدخول
- إنشاء حساب يرسل طلبًا يفعّله المشرف من «الإعدادات»
- صلاحية تعديل وطباعة مستقلة لكل ملف، مع قوالب حسب الوظيفة
- الإعداد: راجع `SETUP-FIREBASE.md`
