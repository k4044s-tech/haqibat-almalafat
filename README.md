# حقيبة الملفات المدرسية

تطبيق ويب يعمل في المتصفح لإعداد الملفات المدرسية وطباعتها لجميع المعلمين والمعلمات:
ملفات الأداء الوظيفي (المعلم/ة، القائد/ة، الوكيل/ة، الموجه/ة الصحي/ة، الموجه/ة الطلابي/ة)،
الخطط العلاجية والإثرائية، الفاقد التعليمي، الخطة التشغيلية، خطة التحسين، الشراكة المجتمعية،
مجتمعات التعلم المهنية، التوجيه الطلابي، الصحة المدرسية، المناوبة والإشراف، النشاط الطلابي، وملفات المعلم.

## المزايا
- تعديل مباشر لأي نص وإضافة صور الشواهد
- 8 ألوان و3 أنماط للغلاف و6 خطوط
- صيغة معلم / معلمة
- طباعة A4 وحفظ PDF
- الحفظ التلقائي في المتصفح دون حساب أو خادم

## التشغيل
افتح `index.html` في المتصفح، أو عبر GitHub Pages.
